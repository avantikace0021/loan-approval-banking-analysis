# Loan Approval & Banking Analysis Project

## 📌 Project Overview

A financial institution wants to analyze customer loan applications, approval patterns, applicant income, credit history, loan amounts, and repayment-related factors.

The objective of this project is to identify factors affecting loan approvals, reduce financial risk, and improve the loan decision-making process using data analysis and visualization.

---

## 🎯 Business Objectives

- Analyze loan approval and rejection patterns
- Understand applicant income and loan amount relationships
- Identify important factors affecting loan approval
- Analyze credit history impact
- Provide business recommendations for better loan decisions

## 🔍 Key Insights

- Total loan applications analyzed: **4269**
- Approved loans: **2656**
- Rejected loans: **1613**
- Loan approval rate: **62.22%**

Key findings:

- Credit score plays an important role in loan approval decisions.
- Higher income applicants generally receive higher loan amounts.
- Applicant financial stability impacts approval chances.
- Data-driven analysis can help reduce lending risk.

---

## 💡 Recommendations

- Use credit score as a major approval factor.
- Implement risk-based loan assessment.
- Monitor rejected applications for improvement opportunities.
- Analyze applicant financial indicators before approval.
- Automate loan evaluation using data-driven methods.
